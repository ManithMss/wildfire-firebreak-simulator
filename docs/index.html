About / How to use

This demo runs the same cellular-automaton wildfire model as the Colab notebook: a grid of cells moves between Unburned, Burning and Burned states (a discrete-time Markov chain), with a vertical firebreak strip of adjustable width down the centre. Wind biases the spread direction, and embers can occasionally jump across the firebreak (shown as glowing sparks flying over the strip).

  • Set firebreak width, wind strength and direction, then press Start to watch one fire spread live. Pause freezes it; Reset applies new settings and restarts.
  • The Quick scenarios buttons load a preset and start it straight away.
  • Press Run Monte Carlo estimate to run many fast simulations and estimate the probability of containment with a 95% confidence interval. Each result is added to the history table so scenarios can be compared.
  • Keyboard: Space start or pause, R reset, M Monte Carlo estimate.
  • Reference check: with the default settings (width 2, wind 0.5, East, seed 42, 50 runs), the Monte Carlo estimate gives 0.700 ± 0.127. This is the same order as the notebook's result for width 2 in Experiment 1. It is not identical because the notebook and this page use different random number generators and grid sizes.
