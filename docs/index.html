About / How to use

This demo runs the same cellular-automaton wildfire model as the Colab notebook: a grid of cells transitions between Unburned, Burning and Burned states (a discrete-time Markov chain), with a vertical firebreak strip of adjustable width down the centre. Wind biases the spread direction, and embers can occasionally jump across the firebreak.

  • Adjust firebreak width, wind strength and direction, then press Start to watch one fire spread live on the grid.
  • Pause freezes the animation; Reset applies new settings and clears the grid.
  • Click Run Monte Carlo estimate to run many quick simulations in the background and estimate the containment probability with a 95% confidence interval.
  • Reference check: with the default settings (width=2, wind=0.5, East), this demo's in-browser Monte Carlo estimate (50 runs) gives a containment probability of approximately 0.6–0.8; this is consistent with the Colab notebook, which reports a similar order of magnitude for this width/wind combination (notebook Experiment 1, width=2 curve). Exact values differ run to run and between the notebook and browser due to independent random seeds, which is expected for a stochastic Monte Carlo estimate.
